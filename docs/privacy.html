Política de privacidad – Cardmarket Highlighter

Última actualización: agosto de 2026

Datos recogidos

Esta extensión no recoge, transmite ni comparte ningún dato personal. Toda la información que gestiona (nombres de usuario y preferencias de color) se almacena exclusivamente en el almacenamiento sincronizado del navegador del usuario (chrome.storage.sync) y nunca sale del ecosistema de Chrome.

Uso de permisos

  • storage: para guardar los nombres de usuario resaltados y las preferencias de color entre sesiones y dispositivos.
  • tabs: para enviar mensajes a las pestañas abiertas de Cardmarket y aplicar el resaltado sin necesidad de recargar la página.
  • *://*.cardmarket.com/*: para inyectar el script de resaltado en las páginas de Cardmarket.

Código remoto

La extensión no carga ni ejecuta ningún código remoto.
